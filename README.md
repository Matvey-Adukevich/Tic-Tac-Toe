# Tic-Tac-Toe

Веб-приложение для игры в "Крестики-нолики" с возможностью игры против компьютера или других игроков онлайн.

## Технологии

- **Java 17+**
- **Spring Boot 4.2.0-M1**
- **Spring Data JPA**
- **Spring Security**
- **PostgreSQL 17**
- **Docker & Docker Compose**
- **HTML/CSS/JavaScript**

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd Tic-Tac-Toe
```

### 2. Запуск базы данных с Docker Compose

```bash
docker-compose up -d
```

Это запустит:
- PostgreSQL на порту `5432` (пользователь: `postgres`, пароль: `1234`)

### 3. Сборка и запуск приложения

```bash
# Windows
gradlew.bat bootRun

# Linux/Mac
./gradlew bootRun
```

Приложение будет доступно по адресу: `http://localhost:1111`

### 4. Остановка базы данных

```bash
docker-compose down
```

## API Эндпоинты

### Создание игры
```
GET /game/new?opponent={VS_PLAYER|VS_COMPUTER}&userUuid={UUID}
```
Создает новую игру. Параметр `opponent` определяет тип соперника.

### Присоединение к игре
```
POST /game/join/{uuidGame}
Body: {UUID} (uuid игрока)
```
Присоединяет второго игрока к существующей игре.

### Получение списка ожидающих игр
```
GET /game/waiting
```
Возвращает список игр, ожидающих второго игрока.

### Получение информации об игре
```
GET /game/{uuidGame}
```
Возвращает текущее состояние игры по её UUID.

### Совершение хода
```
POST /game/play/{uuid}
Body: {
  "grid": {...},
  "userUuid": {UUID}
}
```
Совершает ход в игре с указанным UUID.

## Как играть

1. **Регистрация/Вход**
   - Зарегистрируйтесь или войдите в систему
   - После входа вам будет присвоен уникальный UUID

2. **Создание игры**
   - Выберите тип игры: "Против игрока" или "Против компьютера"
   - Нажмите "Создать игру"
   - Если выбрана игра против игрока, игра появится в списке ожидающих

3. **Присоединение к игре**
   - Нажмите "Обновить список" для получения доступных игр
   - Выберите игру из списка для присоединения

4. **Игровой процесс**
   - Игрок 1 играет за X, Игрок 2 играет за O
   - Введите координаты клетки (строка и столбец от 0 до 2)
   - Нажмите "Сделать ход"
   - Используйте "Обновить игру" для получения актуального состояния
